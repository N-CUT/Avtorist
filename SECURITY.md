# Безопасность

## Как устроена защита
| Слой | Что сделано |
|---|---|
| Процесс окна | `sandbox`, `contextIsolation`, без Node.js, без preload и IPC, без DevTools |
| Контент | Строгая CSP: `script-src 'self'`, `connect-src 'none'`, `object-src 'none'`, `frame-src 'none'` и т.д. |
| Документы | HTML-санитайзер по белому списку (в том числе для вставки ответов ИИ и Markdown), проверка структуры и размеров `.avtorist`/`.scenario`, base64 декодируется без сети |
| Навигация | Запрещены переходы, новые окна, `<webview>`, переход на перетащенный файл. Во внешнем браузере открываются только два адреса: `https://claude.ai/new` и `https://chatgpt.com/` |
| Файлы приложения | Свой протокол `app://` с защитой от path traversal, код в `app.asar` с проверкой целостности |
| Бинарник | Electron Fuses: нет RunAsNode, NODE_OPTIONS, `--inspect`, привилегий file://; загрузка только из ASAR. Проверка целостности ASAR пока включена только на macOS |
| Сеть | Отключена на уровне сетевого стека, сессии и CSP |
| Разрешения | Всё запрещено, кроме списка шрифтов и записи в буфер обмена |

## Ограничения (честно)
- Сборки без платных сертификатов: Mac подписан **ad-hoc** (без Developer ID и нотаризации), Windows-версия без цифровой подписи. Системы не могут подтвердить автора, поэтому проверяй контрольные суммы SHA-256 из релиза.
- На Windows нет проверки целостности `app.asar` (на Mac есть). Подменить код может только тот, у кого уже есть доступ к твоему компьютеру.
- Скомпилированный код можно исследовать: защиты от реверс-инжиниринга нет и не обещается. Секретов в приложении нет.
- Автообновлений нет. Новые версии ставятся вручную из Releases. Это осознанное решение: нет сетевого механизма, который можно атаковать.
