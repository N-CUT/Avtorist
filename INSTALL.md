# Установка и удаление «Avtorist»

- [Mac](#mac)
- [Windows](#windows)

# Mac

## Установка

> **Скачивай только со страницы Releases на GitHub через браузер** (Safari, Chrome). Если файл переслали через Telegram или другой мессенджер из App Store, macOS может вообще не дать его открыть («Не удаётся открыть программу»): она так обращается с файлами, сохранёнными «песочными» приложениями. Тогда просто скачай DMG заново с GitHub.
1. Открой страницу Releases и скачай файл для своего Mac:
   - Apple Silicon (M1/M2/M3/M4…): `Avtorist-1.2.0-macOS-AppleSilicon.dmg`
   - Intel: `Avtorist-1.2.0-macOS-Intel.dmg`
2. (Необязательно) Сверь контрольную сумму в Терминале: `shasum -a 256 ~/Downloads/Avtorist-1.2.0-macOS-*.dmg`. Она должна совпасть со строкой в `SHA256SUMS.txt`.
3. Открой `.dmg` двойным кликом и перетащи «Avtorist» на папку «Applications».
4. Извлеки диск «Avtorist» (кнопка ⏏ в Finder).
5. Запусти «Avtorist» из «Программ» или Launchpad.

### Если macOS не даёт открыть
Приложение распространяется бесплатно и без платной подписи Apple, поэтому при первом запуске macOS может показать предупреждение.
- **macOS 15 Sequoia и новее:** «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть» → ввести пароль.
- **macOS 13 Ventura / 14 Sonoma:** правый клик по приложению → «Открыть» → «Открыть».

Не отключай Gatekeeper целиком и не выполняй команды из интернета, которые предлагают это сделать.

## Обновление
1. Сохрани сценарии на всякий случай: «Экспорт» → «Все сценарии одним файлом».
2. Закрой «Avtorist», перетащи новую версию в «Программы» и выбери «Заменить».
Сценарии хранятся отдельно от приложения и при замене не теряются.

## Удаление
1. Закрой «Avtorist» (⌘Q).
2. Перетащи «Avtorist» из «Программ» в Корзину.
3. Чтобы удалить сценарии и настройки (**безвозвратно**), удали папку:
   `~/Library/Application Support/Avtorist`
   (Finder → «Переход» → «Переход к папке…» → вставь путь).
4. Если есть, удали `~/Library/Preferences/io.github.n-cut.avtorist.plist` и `~/Library/Saved Application State/io.github.n-cut.avtorist.savedState`.

Других файлов, служб, фоновых процессов и элементов автозагрузки приложение не создаёт.


# Windows

## Установка
1. Скачай со страницы Releases файл `Avtorist-1.2.0-Windows-x64.zip` (Windows 10 / 11, 64-бит).
2. (Необязательно) Сверь контрольную сумму в PowerShell: `Get-FileHash $HOME\Downloads\Avtorist-1.2.0-Windows-x64.zip`. Она должна совпасть со строкой в `SHA256SUMS.txt`.
3. Правый клик по архиву → **«Извлечь всё…»** → выбери место, например «Документы» → «Извлечь». Не запускай программу прямо из архива, сначала распакуй.
4. В папке «Avtorist» запусти **`Avtorist.exe`**.
5. Если появится окно «Система Windows защитила ваш компьютер», нажми **«Подробнее»** → **«Выполнить в любом случае»**. Это нужно один раз.
6. Ярлык: правый клик по `Avtorist.exe` → «Закрепить на панели задач» или «Закрепить на начальном экране».

Не отключай SmartScreen и антивирус целиком. Если антивирус ругается, сверь контрольную сумму и разреши запуск только этого файла.

## Обновление
1. На всякий случай сохрани сценарии: «Экспорт» → «Все сценарии одним файлом».
2. Закрой «Avtorist», удали старую папку «Avtorist» и распакуй на её место новую.
Сценарии хранятся отдельно (`%APPDATA%\Avtorist`) и при замене не теряются.

## Удаление
1. Закрой «Avtorist».
2. Удали папку «Avtorist», куда распаковывал архив, и ярлыки, если создавал.
3. Чтобы удалить сценарии и настройки (**безвозвратно**), удали папку `%APPDATA%\Avtorist` (вставь путь в адресную строку Проводника).

Других файлов, служб, записей автозагрузки и записей в реестре приложение не создаёт.
